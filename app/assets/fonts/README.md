# Fontes — Inter (auto-hospedada)

Arquivos `.woff2` da fonte **Inter** (pesos 400/500/600/700, subconjuntos
`latin` e `latin-ext`), servidos localmente para o sistema funcionar **offline**,
sem depender do Google Fonts.

Declarações `@font-face` em `../css/fonts.css`. Origem: pacote
[`@fontsource/inter`](https://fontsource.org/fonts/inter) (licença SIL OFL 1.1).
